# 豆包 / Dola 15s/30s 视频时长解锁助手 (Chrome 扩展 v2.0)

基于前端网络原生劫持技术的 Chrome 扩展程序，用于解锁 Dola / 豆包网页端的 15 秒与 30 秒长视频生成功能。

---

## ⚠️ 重要说明（关于去水印功能）

> [!WARNING]
> **1. 时长解锁功能（15s / 30s）**：✅ **正常有效**  
> 依然可以通过前端网络参数劫持，解除网页端的时长限制，正常生成并导出 15 秒 / 30 秒高清长视频。
> 
> **2. 网页直提无水印功能**：❌ **已失效**  
> Dola 官方已在服务端对视频渲染管线进行更新，统一在视频流中烧录了**全画幅动态漂移水印**（半透明 `Dola AI` 字样且每隔数秒位移）。因此即使拦截到底层原画视频直链，视频本身也已被服务端打上动态水印。
> 
> **3. 动态水印消除解决方案**：  
> 如需去除下载视频中的动态 `Dola AI` 水印，请使用我们配套开源的专用消除工具：  
> 👉 **[dola-watermark-remover (Dola 动态水印自动去除工具)](https://github.com/microshark2024/dola-watermark-remover)**  
> （支持双通道时序轨迹拟合追踪、刚弹出瞬间的动效外推消除与双击/拖拽一键处理）

---

## 🚀 安装步骤

1. 下载或克隆本项目到本地：
   ```bash
   git clone https://github.com/microshark2024/Dola30-unwatermarked.git
   ```
2. 打开 Google Chrome 或基于 Chromium 的浏览器（Edge / Brave 等），在地址栏输入：
   ```text
   chrome://extensions/
   ```
3. 在右上角开启 **「开发者模式 (Developer mode)」**。
4. 点击左上角 **「加载已解压的扩展程序 (Load unpacked)」**，选择本项目根目录。
5. （可选）如需在**无痕（隐身）模式**下使用，请在扩展管理页点击本插件的「详细信息」，勾选「在无痕模式下启用」。

---

## 💡 使用说明与技巧

1. **30s 视频生成**：
   - 在开启新对话时，在界面下方的“时长”选择框中直接选中 **「30s」** 即可。
   - *提示*：输入提示词时，尽量避免直接出现“XX秒”、“X~X秒”等敏感词，以防触发平台的关键词安全拦截。
2. **资源面板**：
   - 视频生成完成后，页面右下角会自动弹出资源面板，方便快速下载捕获的高清视频素材。
3. **后处理去水印**：
   - 将下载的视频文件直接拖入 [dola-watermark-remover](https://github.com/microshark2024/dola-watermark-remover) 的批处理图标上，即可秒级生成纯净无水印成品。
